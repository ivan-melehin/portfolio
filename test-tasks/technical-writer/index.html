App supports incremental backups using CRC checksums. There's a native client daemon running in background that scans FS changes via low-level hooks. For scheduled jobs, we're using a custom task runner built in Rust, and data is stored in a compressed binary format in .dgz containers.

2. РЕШЕНИЕ. Обработайте техническую информацию

How does the backup system work

The app creates backup copies by saving only the new or changed files, which saves time and storage space. A special program runs quietly in the background to track any file changes on your computer. Scheduled tasks are handled by our own tool written in Rust programming language. Your data is stored securely in compact binary format inside «.dgz» container files.

4. РЕШЕНИЕ. Работа с текстом

1. Отредактированный текст

При возникновении ошибки запуска виртуальной машины причиной может стать конфликт идентификаторов UUID. В данной ситуации рекомендуется выполнить следующие шаги:

  1. Убедитесь, что целевая виртуальная машина отключена и не запущена.
  2. Откройте соответствующий конфигурационный файл виртуальной машины, расположенный в директории /etc/pve/qemu-server.
  3. Отредактируйте необходимые значения UUID в данном файле.
  4. Сохраните внесённые изменения и повторно запустите виртуальную машину.

Обратите внимание, что изменение конфигурационного файла возможно только при условии, что виртуальная машина выключена, поскольку работающая машина блокирует доступ к этому файлу.

2. Аннотация

Данный фрагмент описывает процедуру ручного исправления конфликта идентификаторов UUID при ошибке запуска виртуальной машины ВМ. Подробно изложены пошаговые инструкции по редактированию соответствующего конфигурационного файла, расположенного в директории /etc/pve/qemu-server, с обязательным условием отключения целевой виртуальной машины.
