The app creates backup copies by saving only the new or changed files, which saves time and storage space. A special program runs quietly in the background to track any file changes on your computer. При возникновении ошибки запуска виртуальной машины причиной может стать конфликт идентификаторов UUID. В данной ситуации рекомендуется выполнить следующие шаги:

3. Отредактируйте необходимые значения UUID в данном файле.
4. Сохраните внесённые изменения и повторно запустите виртуальную машину.

Обратите внимание, что изменение конфигурационного файла возможно только при условии, что виртуальная машина выключена, поскольку работающая машина блокирует доступ к этому файлу.
